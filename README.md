# Property Exchange 🏠🔁

Pakistan-wide property & vehicle exchange platform in Urdu.
پاکستان بھر میں پراپرٹی اور گاڑیوں کی خرید، فروخت، کرایہ اور تبادلے کا پلیٹ فارم۔

🌐 **Live site:** https://teamworkcomplex-sudo.github.io/property-exchange/

## Features
- **Have / Want listings:** add what you have (میرے پاس ہے) and what you want in exchange (مجھے چاہیے)
- **Categories:** houses, apartments, plots, commercial, shops, offices, factories, warehouses, agricultural land, farmhouses, cars, motorcycles, trucks and more
- **Purpose:** sale, rent or exchange
- **All Pakistan cities:** city selector with search and filters
- **Compare:** compare 2–3 listings side by side
- **Leads:** inquiry form with WhatsApp contact buttons
- **Optional location:** share a Google Maps location only if you want
- **Email alerts:** new listings and inquiries are sent to the owner
- **Login / Signup** for visitors and admin

## Tech
- Single `index.html` file (HTML, CSS, JavaScript)
- Urdu, right-to-left layout, purple theme
- Hosted free on GitHub Pages
